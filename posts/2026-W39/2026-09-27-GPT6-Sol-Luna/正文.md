## 标题（19 字）

AI价格战开打：GPT-6定价直接腰斩

## 正文（发布前请核对字数 ≤1000）

上周二这天很热闹：Anthropic 发完 Claude Opus 5.5 才两个小时，OpenAI 就甩出了 GPT-6 Sol 和 Luna。两家旗舰参数对轰，但真正的战场只有一个字：钱。

OpenAI 把两款新模型的 API 定价直接腰斩（对比自家的 GPT-5.6 促销价），同时把基准分数做到反超。先看价格：Sol 输入 $4 降到 $2、输出 $20 降到 $10；Luna 更狠，输入只要 $0.10。

便宜不等于减配。AutomationBench（覆盖 47 个工具的真实业务流测试）上，Sol 拿到 33.2%，而 Claude Opus 5 满血档只有 26.9%——每任务成本是 Sol 的 11 倍。DeepSWE 基准 Sol 拿 68.8%，距 Fable 5 最高分只差 1.1 个百分点，成本省 80%。

更离谱的是便宜档 Luna：DeepSWE 66.6%，约等于 Opus 5 的水平，每任务成本只要它的 7%。对大多数用不上满血旗舰的任务来说，这等于把"够用"的价位整个打下来了。

Agent 场景真正烧钱的缓存读取，这次直接打到 1 折。GitHub 数十亿请求的实测数据：需要重新处理的 prompt token 占比降了一半以上。OpenAI 还透露了自家内部数据——研究员日均消耗 600 美元的 token，前 10% 的人到 7000 美元。成本曲线不降下来，Agent 是跑不远的。

三点说清楚：①这些是 OpenAI 自选的困难场景评测，不代表日常失败率；②跟 Fable 5.1 的成本对比没算它的 Opus 5 兜底调用——OpenAI 自己在注释里承认这部分出现在约四成任务上；③"错误率减半"是内部口径的评测。

同一天，Claude 说自己便宜了四成，GPT-6 说直接腰斩。价格战正式开打，受益的是所有拿 API 干活的人。
