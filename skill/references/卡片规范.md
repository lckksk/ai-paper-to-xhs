## 真实截图卡（新版默认）

用 `assets/卡片组件.js`（`init / shotBox / shotPair`），它自动给截图套一层**浏览器地址栏外壳**：

```js
const C = require("<skill>/assets/卡片组件.js");
const ctx = C.init({ accent: "1D4ED8", accentDeep: "1E40AF", tint: "E4ECFB" });

C.shotBox(ctx, slide, {
  path: "shots/arxiv-abs.png",
  x: 0.5, y: 2.02, w: 6.5, h: 3.2, fit: "contain",
  url: "arxiv.org/abs/2610.21601",   // 必须与真实 URL 一致
  dark: false,                        // 深底卡传 true
  caption: "arXiv:2610.21601 · 2026-10-15 提交",
});
```

- 外壳构成：顶部 0.28–0.3in 浅灰条 + 三个圆点 + 圆角地址栏（地址用 Consolas 8pt）+ 1px 描边
- `fit:"w"` 按宽度定高（单图）；`fit:"contain" + h` 塞进固定框（多图等高对齐）
- 图注一律放在框下方 0.06in，字号 11.5–12pt 灰色
- 深底封面卡传 `dark:true`，地址栏自动换深色系

版式常量（与旧卡一致，别改）：
- `shotBox` 默认 `barH:0.28~0.3`，截图区高度控制在 **3.0–3.5in**（约占卡片 1/3），下方留出数字行与结论带
- 单张卡里**最多 2 张截图**（`shotPair`），再多就分卡
- 截图**不拉伸、不旋转、不投影**；比例不对用 `contain` 补白，别硬拉

## 规格

- 画布：7.5 × 10 英寸（pptxgenjs `defineLayout`），3:4
- 渲染：`scripts/render_cards.py` → 1242 × 1656 px（PDF 后按 2.3 倍渲染）
- 三张卡：封面卡（深底）→ 内容卡1（方法/要点）→ 内容卡2（数据/结论）
- 封面角标只放「栏目名 + 日期」，**不带期数**：发布前还有人工挑选层，未发布的内容不能带序号（2026-09-26 用户定）

## 调色板（改主题时只换这几个常量）

| 角色 | 值 | 用途 |
|---|---|---|
| BG_DARK | 17181C | 封面底色 |
| BG_LIGHT | FFFFFF | 内容卡底色 |
| ORANGE（accent） | FF6900 | 大数字、大标题第二行、Kicker |
| ORANGE_DEEP | E05A00 | 浅底上的 kicker/强调（对比度比 FF6900 高） |
| TXT_DARK / TXT_GRAY | 1F2024 / 6B6E74 | 浅底正文 |
| MUTED_ON_DARK / GRAY_ON_DARK | 9CA0A8 / C9CBD1 | 深底辅助文字 |
| TINT | FFF1E7 | 结论色带（满宽，必须承载真实内容） |

选择逻辑：accent 取自选题方品牌色（小米→橙）。换选题时换成对应品牌色或领域色，保持「一个主色 + 一个 accent」。

## 版式骨架（保持不变）

- 字体：`Microsoft YaHei`，所有 addText 显式指定 fontFace
- 边距 0.5in；封面大标题 84pt / 内容卡标题 40pt / 正文 16-25pt / 最小 13pt
- 内容卡1：编号行列表（oversized 01-04 数字 + 加粗导语 + 一行说明 + 发丝分隔线）
- 内容卡2：大数字成绩行（52pt 数字 + 右侧标签与区间）+ 满宽 TINT 结论带 + 来源行
- 签名母题 = 超大数字 + 满宽浅色结论带；封面底部放真实数据的迷你柱状图（三根圆角柱，比例真实）

## 禁止（常见 AI 味）

- 卡片内不放 emoji
- 不加装饰性色条/边条/标题下划线；卡片分隔只用发丝线或留白
- 不居中正文；数字右不补零凑长度
- 图内文字每张 ≤40 字（不含来源行）

## 渲染链

1. `NODE_PATH="$(npm root -g)" node 卡片.js` → 卡片源文件.pptx
2. `python <skill>/scripts/render_cards.py 卡片源文件.pptx <输出目录>` → PNG
   （内部：soffice 转 PDF → PyMuPDF 2.3 倍渲染。soffice 未装时脚本会报错并给出安装提示）
3. PNG 交 visual-judge 审
