# 每日发布工作流（每日双发 · 一当场一定时）

> 2026-10-15 定型。发布环节已全自动：`skill/scripts/xhs_auto_publish.js` 一条命令发一篇，
> 由 publish_v12（当场版）与 publish_v13（定时+AI声明版）合并泛化而来，两版均实测成功。

## 每日节奏

| 时间 | 动作 | 说明 |
|---|---|---|
| 10:00 | 论文预处理流水线（自动化） | 采集 sources、初评候选，见台账「候选清单」 |
| 日间 | 成稿 | jiedu-lunwen skill 产出成稿目录（正文.md + 卡片 png） |
| ~14:30 | 双发流水线（自动化） | 第 1 篇当场发；第 2 篇自动定时 +6h（≈20:30，晚高峰） |

**频率铁律**：每天最多 2 篇，间隔 ≥6h，永不超 2；深度版每周 2-3 条。

## 发布命令（核心件用法）

```bash
# 当场发布
node xhs_auto_publish.js --dir "<成稿目录>" --mode immediate

# 定时 +6h（自动计算，分钟级）
node xhs_auto_publish.js --dir "<成稿目录>" --mode schedule

# 定时指定时间
node xhs_auto_publish.js --dir "<成稿目录>" --mode schedule --at "2026-10-16 20:30"

# 验证不走真发（表单走完停住，截图留档）
node xhs_auto_publish.js --dir "<成稿目录>" --mode schedule --dry
```

- node 用绝对路径：`C:/Users/Lenovo/.workbuddy/binaries/node/versions/22.22.2-6/node.exe`
- 脚本自带依赖解析（playwright-core / better-sqlite3），**无需 NODE_PATH**
- 必须后台运行（run_in_background），跑完取输出

## 脚本自动完成的事

1. 解析成稿目录的 `正文.md`：`## 标题` / `## 正文`（末尾 #标签 行自动识别为话题）/ `## 配图`（按清单找 png，缺省则全部 png、封面卡优先）
2. 登录态实时从 `C:/Users/Lenovo/.xhs-mcp/data.db`（xhs-mcp 账号库）导出，无需手工维护 storageState
3. 弹可见 Chrome 全自动：传图 → 标题 → Tiptap 正文 → 话题 → **AI声明「笔记含AI合成内容」（默认必带）** → 定时开关与时间（schedule 模式）→ 点发布
4. 全程截图落盘 `<成稿目录>/publish-logs/`，结果写 `result-<mode>.txt`

## 安全线（不可绕过）

- 定时模式：时间回读校验，**没写成目标值就中止（退出码 3），绝不带默认时间误发即时**
- 定时时间必须晚于当前 5 分钟以上
- 退出码：`0` 成功 / `1` 失败 / `2` 结果不确定 / `3` 安全线中止
- 退出码 3 时**不许改即时发布重试**，留人工处理

## 页面情报速查（踩坑实录）

- 发布按钮是 Shadow DOM 自定义元素 `<xhs-publish-btn>`，一切 DOM/文本搜索搜不到，用坐标 (951,1050) 真实鼠标点击（1920×1080 视口）
- 编辑器是 Tiptap（`div.tiptap.ProseMirror`），Quill 选择器已失效
- 定时开关唯一安全选择器 `.post-time-switch-container .d-switch`；页面第一个 `custom-switch-wrapper` 是**原创声明**，误开会弹权益弹窗
- 所有开关/声明行普通 `el.click()` 会假失败，必须真实鼠标坐标点击
- 时间选择器是 d-date-picker 单框、自带默认值（=当前时间），Ctrl+A 重打 + Enter 覆盖
- AI 声明：点「添加内容类型声明」行 → 下拉点「笔记含AI合成内容」叶子元素

## 收尾动作（每篇发布后）

1. 台账 `topics.xlsx` sheet「发布记录」（真实表头第 4 行）：发布日期、标题、链接（当场版稍后用 `xhs_get_my_notes` 核实补链）、备注注明发布方式
2. 改台账前先备份 `topics-backup-<日期>.xlsx`
3. 结果写入当日工作日志
