# 复盘框架

> 用户回报发布数据后按本框架复盘。方法论来源：blacktwist 数据分析三件套拆解
> （research/小红书自动化调研/），指标口径适配小红书创作中心数据。

## 1. 指标口径（统一，替代混用的「时均浏览/收藏率」）

- **互动率 ER =（赞 + 评 + 藏）/ 浏览 × 100%**——主指标，跨篇可比
- 分指标按需拆：藏率（=收藏/浏览，干货价值）、评率（讨论度）、赞率（轻认可）
- 浏览量受发布时长影响：跨篇比较一律注明「发布至今 N 小时」，必要时按时均校正
- 涨粉单列：粉丝增长是内容组合的结果，不归因单篇

## 2. 两条纪律

- **基准线只与自己历史均值比**，不引用「行业平均」；Top/Bottom 的判定标准就是 ER 高于/低于自己均值
- **不满 72h 的帖子不进 Bottom 榜**（recency bias）。慢热长尾型内容（如酶发现：首日平淡、收藏率最高）会被过早判死刑

## 3. 样本量置信度

- 已发布 < 15 篇：结论一律标注「方向性信号，非定论」，只用于选题倾向，不推翻打法
- 15-30 篇：可以归纳「哪种选题/形式稳定高于基准」
- 30+ 篇：才能做七维规律分析（选题/形式/发布时间/长度/钩子类型/语气/平台）

## 4. 逐篇归因（Top 和 Bottom 各 2-3 篇）

禁止「这篇表现好/差」式结论。每篇写满五个维度：

| 维度 | 问的问题 |
|---|---|
| 选题 | 厂商发布 / 论文深读 / 趣味发现？时效性强弱？ |
| 形式 | 解释型标题 vs 冲突动词式标题？清单式 vs 叙事式？ |
| 钩子 | 开场第一句是哪类（悬念/冲突/数字/分镜）？ |
| 发布时间 | 几点发的？当日热点位次？ |
| 互动引导 | 结尾提问具体吗？有没有给评论区留话头？ |

## 5. 输出结构（写进 weekly/<周次>/复盘.md 或对话汇报）

```
Do More        2-3 条，每条带证据（哪几篇、ER 多少、高出基准几倍）
Do Less        2-3 条，每条带归因（差在哪一维）
下一组实验     1-2 个：假设（如果…就…因为…）+ 测试方式 + 成功判据 + 放弃判据
Stop Doing     有数据支撑的止损 + 替代行为
唯一优先级     如果只改一件事，改什么
```

实验示例（真实候选）：「厂商发布 × 清单式排版」——厂商发布类是我们 ER 最高的选题
（Sonnet 2.90 时均浏览），清单/对比式是高收藏形式，两者从未组合过 → 下次厂商发布
笔记试「三句话档位清单」结构，连续 3 篇 ER 不达均值即放弃。

## 6. 台账落点

topics.xlsx「发布记录」表：互动率列由公式自动算（(赞+评+藏)/浏览）；复盘结论写入
该行「复盘」列，一句话 + 归因维度标签（如「解释型标题失败：形式维」）。
