# 对标打法卡（四位博主的技法浓缩）

> 来源：`research/对标博主分析/对标分析报告.md`（2026-09-26 深度分析：赛博禅心/橘鸦/新智元/井底之硅）。
> 成稿后对照本卡自查；详细论证看报告。

## 写作技法（按优先级）

1. **分镜式开场**（井底之硅）：一句一段、动词驱动、信息逐层加码。「2015年，何恺明画了一条线。」
2. **限时科普模块**：技术铺垫显式打包成「先用30秒搞懂 X」，任何读者都跟得上后文
3. **比喻密度**：每个抽象概念配一个生活类比（信号稀释→一勺高汤越煮越淡）
4. **感性叙事 + 冷酷数据**：故事感性，数字精确到小数（283.6ms→114.4ms、16/18），反差制造可信度
5. **收录反方意见**：呈现社区质疑并公允回应——「流量起来了，纠正也跟着来了」
6. **首尾呼应**：结尾回到开头的意象/人物，闭环收束

## 选题类型（赛博禅心/新智元启发）

- **自制评测实验**：自己给模型出题（如色盲测试）产出一手结论——个人号对抗媒体号的核心武器
- **发布会祛魅**：拨开营销云雾看真实进度
- **人才流动 / 反常识事件**：轻量好写，天然小红书体

## 标题

- 具体数字 + 克制冲突动词（连夜挖走/搞砸了/一刀切掉）；**禁**「秒了/吊打/杀疯了」

## 定位纪律（不抄清单）

- 不拼时效（拼不过机构媒体），拼「尘埃落定后的深度」或次日上午的快速解读
- 不做纯快讯聚合（差异化在解读）；起步期不碰任何变现
