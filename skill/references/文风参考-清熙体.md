# 文风参考卡：清熙体（王庆法）

> 来源样本：王庆法《清熙》2026-10-02《AI斗地主，Nature论文揭示强化学习如何在未知信息中做决策》
> https://mp.weixin.qq.com/s/9anLMlidMqHU9PLTEOFo7w
> 2026-10-14 采纳为文风参考。与「小红书笔记模板.md」「深度版试水规范.md」配合使用。

## 一、样本拆解：这篇为什么好读

**结构骨架**（七个节拍）：

1. **生活场景开场，不报论文名**——从斗地主/扑克的「你永远不知道别人手里有什么牌」切入，两段之后才出现论文。类比先行，术语后置
2. **小标题 = 口语化概念命名**——「先猜牌再出牌」「成本下降几百倍」「最后一张现实牌」。没有一个「01/02」编号，没有「摘要/方法/结论」论文腔
3. **一段一句**——几乎每句话独立成段，移动端扫读零阻力
4. **关键论断加粗**（小红书正文用不了，转移到**封面卡大字**和**内容卡结论行**）
5. **硬核数字精确到个位**——16 张 H100、约 1.63 亿局、2080 亿步、计算量降 500 倍、自博弈少 30 倍。数字是信任，不是装饰
6. **机制讲成动词**——「先猜牌再出牌」「搜索变在线优化」，把术语翻译成动作。全文没有一个「我们提出一个名为 X 的框架」
7. **结尾现实映射 + 收口句不鸡汤**——商业谈判/金融交易/供应链三连对应，最后一句落在判断上（「知道自己不知道什么」），不喊口号不升华

**句式特征**：陈述句为主，设问几乎为零；长短句交替但有明显短句倾向；破折号和括号补语用得克制；无 emoji、无「家人们」、无装腔开场。

## 二、与我们现有流程的兼容性（判断：高度兼容，可直接接入）

| 环节 | 现状 | 清熙体如何接入 |
|---|---|---|
| BRENS 的 E（Easy） | 靠一句话说清 | 类比开场就是 E 的实现手段，写正文第一步先找「生活类比锚点」 |
| BRENS 的 N（New） | 靠独家数字 | 「硬核数字精确到个位」直接强化 N |
| 去AI味工序 | 8 遍+词表 | 清熙体天然是「AI 味」的反面：短段、无设问、无金句堆砌，作为成稿后的自查清单第 9 遍 |
| 卡片 | 每张 ≤40 字 | 正文里的加粗论断 → 封面卡大字；机制动词短语 → 小标题式内容卡标题 |
| 深度版实验 | 3/5 篇进行中 | 清熙体正好是深度版的文风基准，5 篇跑完一起判 |

## 三、成稿时的执行清单（写完逐条过）

- [ ] 开场是生活场景/类比，论文出现在第二段之后
- [ ] 每个小标题是动词短语或口语概念，无编号、无论文腔
- [ ] 正文平均段长 ≤2 句（小红书 1000 字限制下天然成立，卡片文字同理）
- [ ] 至少 3 个精确数字（个位精度优先），且都能在事实核对.md 里定位到原文小节
- [ ] 机制/方法被翻译成动词（「先猜牌再出牌」式），术语首次出现时旁边站着人话
- [ ] 结尾有现实映射（≥1 个具体场景），收口句是判断不是口号
- [ ] 全文零 emoji、零设问开场、零「家人们/姐妹们」
- [ ] 对照样本自查：拿本卡第一节 7 个节拍逐条对

## 四、风险与边界

- **这不是「抄他」**：文风采纳，选题照旧不重叠——他更新慢（周更级）、走长文，我们日更+卡片，赛道不冲突
- **别丢我们的东西**：BRENS 初评、选题门三问、事实核对红线全部保留，清熙体只替换「成稿环节的笔法」
- **顶刊+清熙体是绝配**：Nature/Science 论文自带「听起来厉害」+ 硬核数字，清熙体负责讲人话——两条新改动互相成全
