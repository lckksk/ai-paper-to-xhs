# 知识短片成稿规范（Vibe 知识大赏式，无旁白）

> 2026-10-19 定。适用：小红书「AI 替我说」活动投稿、抖音知识类短片、任何「用动画讲清一个机制」的片子。
> 素材来源与方法论来自 skill `vibe-knowledge-film`（HeyChengC，拆解抖音「Vibe 知识大赏」爆款视频产出）。
> 一条铁律先写在最前：**不要用 AI 配音**。用户 2026-10-19 明确否决 edge-tts 配音版（"语音效果很差"），改成纯配乐 + 字幕 + 强动效后通过。以后所有短片默认无旁白。

## 〇、先判断该不该做视频

| 内容类型 | 做法 |
|---|---|
| 一个机制/原理要讲清（RL 怎么练、注意力在算什么、Agent 为什么调工具） | ✅ 做短片 |
| 一条新闻/一个榜单/一堆数字 | ❌ 做图文卡片帖，别硬转视频 |
| 教程类（点哪里、填什么） | ⚠️ 优先录屏，不是动画 |

判断标准：**这件事能不能在屏上"演"出来**。能演的是动作（写→跑→报错→改），不能演的只有形容词（强大、领先、惊艳）。

## 一、方法论：先找形象，再写文案

这是整个 skill 最值钱的部分，比技术管线重要。

1. **每个概念找一个外行认得的形象**，而且这个形象要长得像概念本身。
   - ❌ 点、线、圈组成的抽象图（观众认不出是什么，等于没画）
   - ✅ 故宫的门钉、镰状细胞、程序窗口、满屏红叉、两根高低不同的柱子
2. **句子里说到什么，屏上就是什么；动词要真的发生**。
   「它自己跑一遍」→ 播放键被按下、窗口张开、游戏真的在动，而不是出现"自己跑一遍"四个字。
3. **提问、命名、结论不硬配图**，约每五句留一句不画。留白是节奏，不是偷懒。
4. **一条片子只讲一个转折**。本片只讲一件事：奖励的尺子从"下一个词准不准"换成"整个项目跑不跑得起来"。其余全砍。

## 三、竖屏改造（官方只做 16:9，改 5 处）

| 文件 | 改什么 |
|---|---|
| `engine/vk.js` | `const W = 1080, H = 1440;` |
| `engine/vk-kit.js` | `SUB.night` 的 `y: Math.round(H*.869)`、`enY: Math.round(H*.921)`；`titleNight` 横线长度 `W*.92` |
| `engine/render.py` | `viewport={"width":1080,"height":1440}`；`sheet` 拼图 `th = tw*4//3` |
| 工程 `index.html` | `canvas{width:100vw;height:133.3333vw;max-width:75vh;max-height:100vh}` |
| `engine/vk.js` | READY 钩子加 `window.__assetsReady`（原版只等字体，不等图片，图会截成空白） |

竖屏安全区：内容只放 **y 180–1180**，字幕在 y=1251。窗口、卡片、图表底部一律不越过 1180。

## 四、写 film.js 的骨架

```js
const T = { type0:.85, type1:2.3, files:2.5, ... };   // 时间表全放顶上，改节奏只动这里
function m1(fr, t, lt) { ... }                         // 一镜一个函数，lt = 本镜内时间
```

- **所有位置都是 t 的纯函数**：不读系统时间、不用无种子随机（用 `hash(i)`）、渲染时不联网。这条保证逐帧确定性，改一个词重渲结果一致。
- 常用绘制：`fr.text / fr.chars / fr.layout / fr.rect / fr.line / fr.circle / fr.glow / fr.spark / fr.comet / fr.cross / fr.tick / fr.windowBox / fr.playBtn / fr.g({a}, fn)` 做分组淡入淡出、`fr.sfx(t, 'tick', {gain})` 打音效事件。
- **照片用 `fr.look.under` 画**：照片不参加辉光合成，颜色才保得住。直接 `fr` 画会被调色盘洗白。
- 片名卡用 `K.titleNight(fr, lt, {zh, sub, en, a, cy, size, track, lineY})`。

## 五、配音/配乐

**不配音**。配乐由 `engine/audio.py` 纯代码合成（drone 长音 + 每章一记泛音钟 + 事件音），不需要版权素材。

在 `film.js` 的 meta 里调：
```js
meta: { title: '许愿式编程', root: -2, noise: [[24.0, 36.0, .32]], silence: [[T.flash-.05, T.flash+.55]] }
```
- `root` 移调（负数更沉）
- `noise` 在指定区间加噪声层（[起, 止, 强度]），用来压过密集字幕段
- `silence` 静音点，放在转场/片名爆闪前，静一拍再炸

出片后**必须做响度归一**，否则手机外放听不清：
```bash
ffmpeg -y -i renders/final.mp4 -af "loudnorm=I=-15:TP=-1.5:LRA=11" -c:v copy -c:a aac -b:a 192k out.mp4
```
实测：合成配乐原始 RMS 只有 -23.6 dBFS，归一后到 -15 LUFS 才正常。


## 七、踩坑清单（都是实测踩出来的）

| 坑 | 症状 | 解法 |
|---|---|---|
| `fr.text/chars/layout` 默认 `align:'c'` | 左对齐文字跑到屏幕外、被裁一半 | 每次显式传 `align:'l'` |
| 图片路径 | 截图里图片区全空 | HTML 在 `film/` 子目录，素材要写 `../assets/xxx.png` |
| 环形图节点不等距 | 光点轨迹与节点错位 | 节点角度必须均分 `ang = i * 2π/n - π/2` |
| 为了腾地方把主体缩小 | 字糊成一团，观众读不清 | 宁可让旧内容**上移+淡出**，不要缩主体 |
| 镜头之间留黑场 | 拼图里出现纯黑格 | 下一镜提前 0.3-0.8 秒进（`T.s3` 往前挪） |
| 结尾前光点太稀 | 收尾显得空、拖 | 星点 240 个起，`r0 = 360 + hash*620`，加中心核 `spark` 收束 |
| `edge-tts` 报 403 | Sec-MS-GEC 鉴权过期，与代理无关 | 本流程已不配音；若确需 TTS，升级到 ≥7.3.1 |
| 渲染出声但太小 | 手机外放听不见 | loudnorm I=-15 |
| 字体下载被掐断 | `get_fonts.py` 中途断 | `curl -x http://127.0.0.1:7897` 逐个下 |

## 八、审查标准（渲全片之前必须过）

1. `--sheet 16` 里**没有纯黑格**、没有连续两格几乎一样（说明卡住了）
2. 每屏**下半页不留大片空白**——空就加装置（概率条、报错列表、进度条），不要留白
3. 任何一帧抽出单看，**有没有一个能叫出名字的东西**（赛车、窗口、红叉、柱状图）；只有文字就是不合格
4. 字幕断词不能断在半个词组上（"全部真/实可玩"这种要改文案或改行宽）
5. 片尾必须有**出处小字**（素材来源 + 示意声明）

## 九、发布规范

**两个平台两份文案**，成稿目录里分开存：

| 文件 | 平台 | 要点 |
|---|---|---|
| `正文.md` | 小红书 | 标题 ≤20 字；正文 300-600 字；话题放最后一行；活动话题（如 #AI替我说 #用AI讲知识）必带 |
| `发布文案-抖音.md` | 抖音 | 标题 ≤55 字（前 8 字要能独立成立）；简介首两行是钩子；话题 5 个（1 大流量 + 2 精准 + 1 热点 + 1 泛用）；附搜索埋词 |

两平台共通：
- **发布永远人工**，自动化止步于成稿（2026-10-17 平台判定 AI 托管发文，账号级处罚先例）
- 发布时必须勾 AIGC 声明（小红书「笔记含 AI 合成内容」/ 抖音「内容由 AI 生成」）
- 片中代码、报错、分数**只要不是真实日志，必须在画面 + 片尾小字双标注「示意」**
- 官方演示画面标「官方演示/来自 XX 官方发布」

## 十、尺寸决策

母版定 **1080×1440（3:4）**，两平台通用：

- 小红书：原生 3:4，满屏
- 抖音：主推 9:16，但支持 3:4（上下留黑边，实际显示略小）

为什么不直接做 9:16：这类片子的主体是**程序窗口、报错列表、环形图、柱状图**，横向展开才看得清，硬拉 9:16 会把代码行压成一条缝。除非选题本身就是纯竖构图（人物、手机录屏），否则不做 9:16。
